01·Background

What Is a World Model?

An actor chooses an action.

A world model imagines what happens next.

A critic evaluates the imagined outcome.

DreamerV3, MuZero, TD-MPC2

Actor
World model
Critic
  • [Hafner et al., 'Mastering Diverse Control Tasks through World Models']

We can separate this into three roles. The actor chooses what to do. [click] The world model imagines the result of that action. [click] The critic judges whether that result is good or bad. [click] Existing methods like DreamerV3, Muzero, and TD-MPC2 combine these parts and learn with rewards. The critic's value helps guide action selection.

Our first idea is to describe each action in words. [click] We keep direction and magnitude, but also state what they mean: move a pusher, apply a force, or rotate a gripper. [click] A video caption now fits the same interface. We no longer need an action vector for every training example. [click] All these descriptions become the same kind of condition. One predictor can learn across domains.
